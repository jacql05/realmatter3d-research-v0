## Thesis (one paragraph)

For single-image reference ↔ generated-3D fidelity work, convenient automated
signals are **not** automatically interchangeable with reference-grounded
human-visible fidelity. Meaningful comparison requires an explicitly named
comparison pair, declared observation / confounder conditions, disciplined
separation between human judgment and machine instruments, and hard claim
ceilings. Quantitative fidelity scoring and proven reference-grounded repair
are **not** established.

V0 is intentionally:

```text
negative results
+ measurement discipline
+ open research questions
```
